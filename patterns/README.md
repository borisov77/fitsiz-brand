# Patterns — FITSIZ

Фирменные текстуры и паттерны FITSIZ для использования в баннерах, презентациях, упаковке и digital-коммуникации.

## Идея

Визуальный язык FITSIZ — **индустриальный**: сталь, сварочный цех, производство. Паттерны поддерживают эту тему, не перетягивая внимание с логотипа и продукта.

## Правила использования

- Все текстуры — **чёрно-серые**, без цвета. Цветом добавляем только брендовый зелёный `#42BA1A`.
- Поверх паттерна всегда нужен **полупрозрачный чёрный слой** (overlay) для читаемости:
  - overlay `#121212` с прозрачностью 60–80% для заголовков;
  - 30–50% для spot-иллюстрации.
- **Нельзя**: ставить логотип поверх самой контрастной части текстуры без чёрной подложки.
- **Нельзя**: заменять зелёный акцент на другой цвет даже на паттерне.
