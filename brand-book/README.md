# Brand Book — FITSIZ

Официальный брендбук FITSIZ 2024.

## Файлы

| Файл | Назначение |
|---|---|
| `fitsiz-brandbook-2024.pdf` | Публикуемая PDF-версия брендбука. Для партнёров, дистрибьюторов, подрядчиков. |
| `fitsiz-brandbook-source.fig` | Исходник Figma — редактируемая версия со всеми лого, цветами, паттернами, примерами макетов. Внутренний файл команды FITSIZ. |

## Что внутри брендбука

- Позиционирование и миссия FITSIZ
- Логотип и его варианты
- Охранное поле и запрещённые приёмы
- Фирменная палитра (черный `#121212`, белый `#FFFFFF`, зелёный `#42BA1A`, лайм `#C2D918`)
- Типографика (Russo One для заголовков, Inter для текста)
- Визуальный язык: pill-формы, карточки 24–32 px, плоская заливка
- Примеры применения: упаковка, digital, POS, соцсети
- Tone of voice и правила коммуникации

## Как использовать этот файл

1. Партнёрам и подрядчикам — присылать PDF.
2. Дизайнерам FITSIZ — открывать `.fig` через Figma.
3. Web / AI-агентам — ориентироваться на цифровую копию правил в `.ai/CONTEXT.md` и `.ai/RULES.md` в корне этого репо.

## Версия

- 2024.1 — текущая актуальная редакция.
- Для обновления обращаться к внутреннему дизайн-отделу FITSIZ.
