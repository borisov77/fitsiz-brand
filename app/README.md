# App — FITSIZ APP

Графические ассеты приложения **FITSIZ APP** — цифровой помощник владельца сварочной маски FITSIZ.

Сайт приложения: **fitsiz.app**
Доступность: Google Play, RuStore (Android), Web PWA. iOS — в процессе.

## Что делает приложение

- **Подбор маски** — ассистент на AI задаёт вопросы и рекомендует модель.
- **Настройка маски** — видеоинструкции по каждой модели.
- **AI-анализ сварного шва** — пользователь фотографирует шов, приложение оценивает качество.
- **Служба поддержки 24/7** — живой чат + AI-бот по вопросам гарантии и ремонта.
- **Профиль сварщика** — Welder ID, дата регистрации, расширенные настройки.

## Правила использования скринов

- Не изменять соотношение сторон, не растягивать.
- Не накладывать текст или лого поверх без согласования — в скринах уже есть UI.
- Для промо-рендеров вставлять скрины в **тёмные mockup-устройства** (iPhone / Pixel), фон — `#121212`.
- В соцсетях допустимо обрезать статус-бар.

## Иконка приложения

- Rounded square (радиус ~22%, iOS-стандарт), центрированный знак `fs` + лепестки.
- Единственный цвет подложки — `#121212`.
- Акцентный лепесток — `#42BA1A`.
- **Нельзя** менять подложку на белую или ставить градиент.
