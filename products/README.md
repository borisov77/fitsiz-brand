# Products — FITSIZ

Каталог сварочных масок FITSIZ. Каждая модель — в отдельной папке `fitsiz-<model-name>/`.

## Структура папки модели

```
fitsiz-<model-name>/
├── info.md           — характеристики, SKU, для кого, сценарии применения
├── main.png          — главное фото (прозрачный или белый фон, анфас)
├── lifestyle-01.png  — в использовании / деталь / ракурс
├── lifestyle-02.png
├── …
└── box.png           — упаковка (если есть)
```

## Соглашения по именованию

- **Только латиница**, нижний регистр, дефисы вместо пробелов.
- Название папки: `fitsiz-<корпус>-<модификатор>`, например:
  - `fitsiz-element-classic`
  - `fitsiz-element-hd-color`
  - `fitsiz-expan-hd-ultra`
  - `fitsiz-program-mask-7000`
- Главное фото **всегда** называется `main.png` (прозрачный фон) или `main.jpg` (белый фон студия).
- Фото в использовании — `lifestyle-01.jpg`, `lifestyle-02.jpg`, …
- Упаковка — `box.png`.

## Линейки масок

| Корпус | Назначение | Модели |
|---|---|---|
| **Element** (стационарный) | универсальные маски для ручной и полуавтоматической сварки | DIN 9/10/11, Starter Base, Static, Static Max, Classic, HD Color, HD Argon, HD Solar, HD Spector, HD Lumen, HD Optic |
| **Expan** (расширенный обзор) | премиум-модели с большим смотровым окном | HD Ultra, HD Hyper, HD Hyper Pro |
| **Program Mask** (панорамные, TIG/MIG/MMA) | топ-уровень, цифровая регулировка, совместимость с каской | Program Mask 7000, 8000 |
| **Flip** (откидная) | DIN-филтр + откидной корпус для зачистки | FSC-FD010, FSC-FB101, FSC-FP530 |

## info-template.md

Каждая модель описывается по единому шаблону. См. `info-template.md`.

## Источник данных

Характеристики каждой маски взяты из внутренней таблицы FITSIZ «Информационные таблицы FITSIZ для каталога 2026.xlsx». Все описания проверены и актуальны на момент публикации.

## Цены и штрих-коды

Розничные цены (RU) и EAN-13 коды указаны справочно. Для актуальных цен — уточнять у fitsiz.ru / отдела продаж.
