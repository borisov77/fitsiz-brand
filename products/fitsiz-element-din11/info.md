# FITSIZ DIN 11

> Пассивная маска DIN 11 для работы с интенсивной дугой. Максимально тёмное стекло.

## Основные характеристики

| Параметр | Значение |
|---|---|
| Полное наименование | Сварочная маска FITSIZ ELEMENT - DIN 11 |
| Артикул (SKU) | FSC-D011 |
| EAN-13 | 4660059745015.0 |
| Корпус | Element |
| Материал корпуса | полипропилен |
| Смотровое окно | 110x90 мм |
| Площадь видимой области | 9900 мм² |
| Наголовное крепление | E-1 |
| Регулировок оголовья | 6.0 |
| Налобный обтюратор | есть |
| Затылочный обтюратор | есть |
| Защита корпуса S-FIRE | есть |
| Подходящие виды сварки | MMA, MIG/MAG |
| Температура эксплуатации | от -45°C до +80°C |
| Масса нетто | 0.38 кг |
| Гарантия | 12 мес |
| Сертификат | ТР ТС 019/2011 |
| Страна производства | Россия |
| Розничная цена (RU) | 819,93 ₽ |

## Для кого

Сварщики, работающие с сильной дугой и большими токами.

## Сценарии применения

- Тяжёлая MMA
- Наплавка, резка
- Длительные смены при ярком свете

## Расходные материалы и комплектующие

| Артикул | Что это |
|---|---|
| FSC-ELOUT | Комплект внешних защитных стёкол |
| FSC-E-1 | Наголовное крепление E-1 |

## Упаковка

- Габариты: `250.0 × 250.0 × 300.0 мм`
