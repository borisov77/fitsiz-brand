# MISSING.md — чего не хватает перед публикацией

Чек-лист ассетов, которые нужно дособрать, прежде чем делать репозиторий публичным и рассылать партнёрам.

Разбито по папкам, чтобы удобно закрывать пункт за пунктом.

---

## 1. logos/

- [ ] **SVG-версии всех логотипов.** В репозитории сейчас только PNG. Для web, иконок, анимаций и печати нужны векторы: `fitsiz-logo-black.svg`, `fitsiz-logo-white.svg`, `fs-monogram-black.svg`, `fs-monogram-white.svg`, `fitsiz-logo-full-company-black.svg`, `fitsiz-logo-full-white.svg`.
- [ ] **EPS / AI-версии** для полиграфии (упаковка, баннеры, печатная реклама).
- [ ] **favicon-пакет**: `favicon.ico` (multi-size), `apple-touch-icon.png` (180), `android-chrome-192.png`, `android-chrome-512.png`.
- [ ] **Monochrome-версии** логотипа — только чёрный или только белый, без зелёного лепестка (для одноцветной печати, штампа, тиснения).

## 2. colors/

- [ ] **Pantone-подборка** для упаковки и печати.
- [ ] **ASE / ACO-палитра** для Adobe Illustrator / Photoshop.
- [ ] **sRGB / Display P3-профили** — если планируется dark-UI премиум-уровня.

## 3. typography/

- [ ] **Локальные .woff2-файлы** Russo One и Inter (на случай офлайн-сборок, печатных файлов, PWA без интернета).
- [ ] **Kirilliзированные шрифты** — убедиться, что все веса Inter поддерживают русский (да, поддерживают — добавить ссылку в README).
- [ ] **Образцы типографики** — картинка-постер с «fitsiz» во всех размерах и стилях.

## 4. products/

Сейчас в каждой папке модели используются «повторные» фото (одно и то же оголовье E-1, одинаковые side-body-шоты с логотипом). Это временно. Для полноценного каталога нужно:

- [ ] **Студийная съёмка каждой маски** на белом / прозрачном фоне, 5 ракурсов: фронт, 3/4, профиль, сзади, сверху. Формат — PNG на прозрачном фоне + JPG на белом.
- [ ] **Детали и ключевые фишки** каждой модели: светофильтр, регулировки, крепление оголовья, сенсоры. 2–4 крупных плана на модель.
- [ ] **Lifestyle-съёмка** с живыми сварщиками в цехе / на стройке — минимум 2 варианта на модель (общий план + деталь).
- [ ] **Фото упаковки** (`box.png`) каждой модели. Сейчас отсутствует для всех моделей.
- [ ] **Фото в руке / на голове** для мобильного каталога.
- [ ] **Студийная съёмка CHAMELEON** — если будет отдельная линейка Chameleon, её фото ещё нет. Пример в задании `fitsiz-chameleon-777`.
- [ ] **Отдельные папки для FLIP-масок** (`fitsiz-flip-din10`, `fitsiz-flip-base`, `fitsiz-flip-program`) — сейчас фото только в Excel как характеристики, фото нет.
- [ ] **Отдельные папки для аксессуаров / расходников** — внешние и внутренние стёкла (FSC-ELOUT, FSC-EXOUT, FSC-9651IN…), крепления (FSC-E1, E2, H1), очки. В текущем каркасе они вынесены в «комплектующие» внутри `info.md`, но когда появятся отдельные фото — можно выделить в `products/accessories/`.
